StemLab para Linux (x86_64)
===========================

ESPAÑOL

  Abrir StemLab:            ./StemLab
  Añadirlo al menú:         ./install.sh     (sin permisos de administrador)
  Quitarlo del menú:        ./uninstall.sh

  Lleva dentro su propio Python con PyTorch (CPU) y Demucs: la separación de
  instrumentos funciona sin instalar nada más. La primera separación descarga
  el modelo (unos 80 MB).

  Necesita un Linux de 64 bits con glibc 2.39 o posterior (Ubuntu 24.04,
  Fedora 40, Debian 13...) y las bibliotecas habituales de un escritorio. Si
  al abrirlo falta alguna, en Ubuntu / Debian:

      sudo apt install libasound2t64 libfreetype6 libfontconfig1 libx11-6 \
          libxext6 libxinerama1 libxrandr2 libxcursor1 libxrender1

  StemLab se queda en esta carpeta: puedes ponerla donde quieras (si la mueves
  después de ./install.sh, vuelve a ejecutarlo).

ENGLISH

  Open StemLab:             ./StemLab
  Add it to the menu:       ./install.sh     (no root needed)
  Remove it from the menu:  ./uninstall.sh

  It bundles its own Python with PyTorch (CPU) and Demucs: instrument
  separation works with nothing else to install. The first separation
  downloads the model (about 80 MB).

  It needs 64-bit Linux with glibc 2.39 or later (Ubuntu 24.04, Fedora 40,
  Debian 13...) and the usual desktop libraries. If one is missing when you
  open it, on Ubuntu / Debian:

      sudo apt install libasound2t64 libfreetype6 libfontconfig1 libx11-6 \
          libxext6 libxinerama1 libxrandr2 libxcursor1 libxrender1

  StemLab stays in this folder: put it wherever you like (if you move it after
  ./install.sh, run it again).
